## ⑥ 专项判定：金额输入 `0` 的提示文案

**判定：按规范，现实现正确，不是缺陷，不建议在 v0.2a 改。**

- `design-spec.md` v1.1 §2.8 边界值表原文：`0` → 拦截 → 界面表现「**请输入提现金额**」。
- §2.8 校验顺序为「格式 → 最低 → 余额 → 最高 → 收款账户 → 提交」，但边界表对 `0` 单独给了「请输入提现金额」，实现与边界表逐字一致（`money.js` 中 `cents === 0` 单独返回 `empty`）。
- 相邻的 `0.01` 才应走最低额提示，C-12 实测为「单笔最低提现 ¥100.00」，也符合规范。
- 若产品确实希望 `0` 提示“最低 100”，应先改 §2.8 边界表，再改实现；不能以实现反推规范。当前不改。
