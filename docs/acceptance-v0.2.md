## 1. 两段闸门

### 1.1 首轮准入（Gate 1）

**目的**：判断斯派克这一版能不能作为 v0.2 的可用基线，能不能进入终验。

| 闸门 | 必须满足 | 涉及用例 |
|---|---|---|
| 硬闸 1：P0 判据 | v0.2 的 17 个 P0，逐条判据全为「是」 | A 组 100 条 |
| 硬闸 2：导航 | 无错跳、无自跳、无「点了没反应」；未开放项为禁用 + 说明 | B-NAV 8 条 |
| 硬闸 3：金额 | 整数「分」运算；边界表逐行正确；无浮点、无三位小数、无科学计数法 | C 组 15 条 |
| 硬闸 4：新页三态 | A07 / M12 / A08 / M13 / M14 的默认、空、错误态齐全且可操作 | B-ST 20 条 |
| 配套 | MP-86 闭环可走通；5 个新页功能验收通过 | B-P86 5 条 + B-A07/M12/A08/M13/M14 28 条 |

**Gate 1 判定：**

- 全部 176 条为「是」→ **首轮通过**，进入终验。
- 任一条为「否」→ **首轮退回**，按 §7.3 逐条列出，不进入终验。
- 四条硬闸必须单独签字；任一条硬闸为「否」，即使其他用例全过也判退回。

### 1.2 终验（Gate 2）

**目的**：判断这一版能不能作为 v0.2 交付/对外演示。

| 闸门 | 必须满足 | 涉及用例 |
|---|---|---|
| 六态全矩阵 | 17 原有屏 + 5 新页，共 22 屏，六态逐格可见或书面「不适用 + 承接页」 | D-01～D-22 |
| 小屏适配 | 390 × 844 无横向滚动、壳尺寸正确；320 宽无横向滚动；后台 1024 / 1440 达标 | D-23～D-26 |
| 线上质量 | console error = 0、资源 404 = 0 | D-27 |
| 核心链路 | 进件 → 商户 → 门店 → 码牌 → 交易 → 收益 → 提现 → 审批 → 代付，一条链可点穿 | D-28 |
| 全量回归 | 首轮 A/B/C 206 条全部重跑通过 | D-29 |
| 性能 | 有实测数字；纯静态原型无接口时，书面写「不适用 + 原因」，不得留空 | D-30 |

**Gate 2 判定：**

- 全部为「是」→ **可交付/可演示**。
- 存在 P0/P1 未清零 → **不可交付**，不得降级。
- 仅存在已书面告知的 P2/P3 且队长与用户确认 → **有条件交付**，条件逐条列明。

### 1.3 结论分级（只用于终验）

| 结论 | 条件 |
|---|---|
| 可交付/可演示 | P0=0、P1=0，Gate 2 全过，遗留 P2/P3 已记录 |
| 有条件交付 | P0=0、P1=0，存在不影响主链路且已书面确认的 P2；条件必须可验证 |
| 不可交付 | 任一 P0/P1 未闭环，或 Gate 2 任一硬项为「否」 |

> 首轮只有「通过 / 退回」两种结论，不设「有条件通过」。

**补充判定（随 C 组执行，不重复计数；与 C-15 重叠处只记一次）：**

- 任意金额计算走整数「分」，不用 `parseFloat` 直接乘 0.08；`0.1 + 0.2` 类输入不出现 `0.30000000000000004`。
- 展示统一两位小数 + 千分位；负数用 `−`（U+2212），不显示为正数。
- 手续费公式取 `min(amount, round_half_up(amount × 8%) + 300)`，四舍五入到分。
