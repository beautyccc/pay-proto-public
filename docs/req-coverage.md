## 0. 结论摘要

| 指标 | 数量 | 说明 |
|---|---|---|
| 需求编号总数 | 138 | MP 71 + AD 67 |
| 已覆盖 | 60 | 其中完整 24，部分 36 |
| 未覆盖 | 55 | 均为本期原型未承载（MP 26 / AD 29） |

**一句话结论：** 17 屏把“进件 → 商户 → 收益 → 提现”的主干立住了，但一期还有 **24 个 P0 缺口**；其中门店（MP-40/41）、码牌（MP-50/51/52）、交易查询（MP-60/61/62）、代理树与注册审核（AD-10/11）、提现审批（AD-50/51）会直接让主链路或资金闭环走不通。v0.2 排期的 3 页只能消掉 7 个编号（AD-10、AD-50、AD-51、MP-33、MP-50、MP-51、MP-52），**不足以覆盖全部 P0**，需要队长决定剩余 P0 是进 v0.3 还是明确“本期不做”。

> **2026-11-11 更新**：队长已裁决 v0.2 扩为 17 个 P0（不再只是 3 页），另含 P1 附加项 MP-86；本节为 v0.1 时点快照，最新归属见 §6。

> **2026-11-11 晚 口径更新（现行，队长裁决）**：新增 **P0-25「我的」模块**（MP-120～127），归属 **v0.3 / P0**，负责人小程达。**P0 缺口 24 → 25；v0.3 7 → 8；P1 缺口 67 → 60**（MP-120～126 共 7 个编号由 P1 升 P0；MP-127 由「已覆盖」并入模块验收）。MP-122 并入 MP-120，不新增菜单行。§0 摘要、§4.1/§4.2 与 §6 中的 24/7/67 计数为 v0.1 时点快照，**保留原样不改写**；现行口径以本条、§6.13 与 `docs/p0-breakdown.md` P0-25 为准。

## 1. 核对口径

### 1.1 结论定义（三选一）

| 结论 | 判定标准 |
|---|---|
| 已覆盖 | 界面有明确承载（页面、区块、按钮、字段、状态至少之一），用户可到达 |
| 未覆盖 | 无任何界面承载，或入口存在但点击无落地、无法到达 |
| 不适用 | §14 明确排在二期 / 三期，或明确不在本期范围 |

> 注：结论为“未覆盖”但填了屏号，表示该能力应落在该屏、现屏上没有对应元素；结论为“不适用”但填了屏号，表示现有入口所在位置。

### 1.2 完整度（补充信息，不替代结论）

| 完整度 | 含义 |
|---|---|
| 完整 | 需求要点在界面可逐项指认 |
| 部分 | 有承载，但缺字段、缺状态、缺异常分支或缺交互 |
| 无 | 无承载 |

### 1.3 优先级定义（只用于缺口）

| P1 | 不影响主闭环的字段 / 状态 / 分支，或非主链路的一期缺页，或二期范围 |
