# 聚合支付 · 代理商展业系统 — 高保真可点原型

> 依据《聚合支付产品-需求范围说明书 v1.1》制作，用于业务与设计对齐、评审演示。
> **全部数据为演示数据（mock），不连接任何真实通道、不产生任何资金动作。**

在线预览：https://beautyccc.github.io/pay-proto-public/

## 两个端

| 入口 | 说明 |
|---|---|
| `index.html` | 代理端（微信小程序观感），手机壳内可点击 |
| `admin.html` | 运营后台（桌面 Web），左侧导航切换 |

顶部「小程序端 / 运营后台」可互相跳转。

## 已覆盖页面（P0，17 屏）

**代理端 11 屏**：启动说明页 / 登录 / 邀请码注册+实名 / 实名审核中 / 首页看板 / 商户列表 / 商户进件（通道卡片）/ 商户详情（三态看板）/ 收益（六科目）/ 提现 / 我的

**后台 6 页**：商户列表 / 商户详情（三态+操作日志）/ 费率矩阵 / 分润引擎 / 通道管理 / 对账中心（差错池）

## 原型里刻意做对的几件事

- **金额单位**：业务口径为整数「分」，页面展示换算为元并保留两位；提现试算按 `8% + 3 元/笔` 计算并标注「费率待确认」。
- **三态看板**：进件 / 签约 / 报备分开呈现，允许不同步——这是需求文档里最容易做错的地方。
- **通道状态**：一期三家（银盛基准、拉卡拉、易生试运行），支付宝大额按三期「暂停新增」处理。
- **六科目**：日结分润 / 月结分润 / 日结奖励 / 月结奖励 / 分成奖励 / 增值收益（未开通），各自独立提现。

## 本地运行

纯静态，无需构建：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080/
```
